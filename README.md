# demand-forecast-pipeline

Weekly retail demand forecasting run by Airflow: retrain, compare challenger against
champion, promote only if better, and publish a dashboard with an LLM-written summary.

Status: **planned**. The design, stack, milestones, evaluation and hosting plan are in
[docs/ROADMAP.md](docs/ROADMAP.md). Code lands milestone by milestone, starting with M0.
